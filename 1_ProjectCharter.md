## Purpose
### Problem to solve
In my case, 2025 is but a blurry memory. I can't remember what movies, books (if any) and barely a couple of games I've might have enjoyed.
Rating, reviewing, spending more time around the memory of what's been enjoyed helps it sink in, and even though it's passed, it makes the overall experience more memorable.
Capyloga aims to offer a free, self-hostable, private, UX oriented and shareable option.

### Reason (for the project)
- Review, remember and rate the things you have (or haven't) enjoyed.
- Offer a better alternative than spreadsheets.
- Be the go-to option for making backlogs without paywalls, ads nor privacy concerns.

### Expected benefit
- Personal use
- Community's enjoyment

## Scope
### In scope
- User authentication
- CRUD Backlogs
- CRUD Backlog logs
- Detailed view of Backlog logs
- Save Backlog as JSON (and possibly other formats)
- Make Backlog public (opt-in)
- Monthly/yearly recaps
- API Documentation (future app?)
- User stats & graphs

### Out of scope
- Friend lists
- Chat
- Notifications

### Expected deliverables
- Functional user authentication (endpoints, view, skeleton)
- Functional backlog CRUD (via endpoints, protected by auth)
- Functional backlog log CRUD (via endpoints, protected x2)
- Backlog log details view (frontend)
- API Documentation (endpoints, params, etc.)
- Generaton of user stats & graphs
- Save backlog as JSON

## Goals
### Project-level "done" Criteria
